## 🎯 Value Proposition

**Urion** is a multi-IDE safeguard framework engineered to eliminate AI code hallucinations, structural decay, and security vulnerabilities in projects built with AI coding assistants (_Cursor, Claude Code, Windsurf, GitHub Copilot, Trae, Roo, Cline_).

---

## 🛠️ Key Features

- **Multi-IDE Native Support**: Single source of truth automatically synchronized for Cursor, Windsurf, Copilot, and Claude.
- **Zero Production Dependencies**: Lightweight, ultra-fast, and secure against supply chain attacks.
- **Feature-Sliced Design (FSD)**: Clean architecture enforcement for Node.js / TypeScript backends and React frontends.
- **OWASP Top 10 Security**: Native protection rules against SQL Injection, XSS, CSRF, insecure CSP, and PII leaks.
- **Prisma & PostgreSQL ACID Persistence**: Built for production-grade reliability.

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/joaoschaun33-cloud/Urion-Dev-Vibe-Coding-Safeguard.git
cd Urion-Dev-Vibe-Coding-Safeguard

# Run first-time setup
npm run setup

# Execute Smoke Tests & Cursor Doctor
npm run test:smoke
npm run cursor-doctor
```
